# Annotation App

Web app for creating, testing, and managing annotation schemas.  

## Features (planned)
- Define custom annotation schemas
- Upload and view annotated data
- Run verification and quality checks
- Export annotations in standard formats

## Tech stack (planned)
- Python (FastAPI or Flask)
- Tailwind CSS for frontend
- SQLite/Postgres for storage
